# راهنمای کلاینت Windows راحت وی‌پی‌ان

## این نسخه چه کاری انجام می‌دهد؟
- کلاینت WPF با موتور رسمی sing-box نسخه 1.14.4 برای Windows x64 بسته‌بندی می‌شود.
- لینک‌های VLESS + REALITY با انتقال TCP پذیرفته می‌شوند؛ پروفایل‌های OpenVPN، WebSocket، gRPC، XHTTP و دیگر انتقال‌های پشتیبانی‌نشده رد می‌شوند.
- وقتی کادر لینک سرور خالی باشد، برنامه فهرست عمومی را خودکار از مخزن FLAT447/v2ray-lists دریافت می‌کند. برای دسترسی‌هایی که یک دامنه در دسترس نیست، CDN و آدرس‌های جایگزین امتحان می‌شوند.
- فهرست ورودی با همان parser اتصال بررسی می‌شود؛ فقط پروفایل‌هایی با UUID، کلید عمومی REALITY و پارامترهای قابل‌قبول و TCP باقی می‌مانند. حداکثر پنج کاندید به مرحله اتصال می‌روند.
- در صورت تمایل، کاربر می‌تواند به‌جای دریافت خودکار، تا پنج لینک سازگار را خودش وارد کند.
- برنامه هر کاندید را به‌ترتیب با sing-box امتحان می‌کند؛ کاندیدی نگه داشته می‌شود که بررسی HTTPS خروجی IPv4 از داخل تونل موفق شود و IP آن با مقدار قبل از اتصال متفاوت باشد. کاندید ناموفق پیش از امتحان بعدی متوقف می‌شود.
- برنامه یک رابط TUN با Full Tunnel و strict routing می‌سازد؛ شبکه‌های خصوصی، loopback و link-local برای دسترسی LAN مستثنا می‌شوند.
- DNS از طریق HTTPS به Cloudflare DoH و از مسیر پروکسی تنظیم شده است.
- پیکربندی تولیدشده قبل از اجرا با دستور sing-box check بررسی می‌شود.
- اطلاعات خام لینک یا خروجی موتور در فایل گزارش Raahat ذخیره نمی‌شود.
- Windows Job Object با پرچم Kill-on-close برای بستن پردازش موتور در زمان خروج برنامه استفاده می‌شود.

## منبع فهرست رایگان
منبع اولیه فهرست، پروژه عمومی FLAT447/v2ray-lists و فایل BLACK_FULL.txt است. برنامه از CDN jsDelivr و دو mirror عمومی GitHub استفاده می‌کند. این فهرست یک منبع شخص ثالث است و Raahat مالک یا گرداننده سرورها نیست.

وجود یک لینک در فهرست به معنی سالم بودن آن از شبکه شما نیست. تست نهایی فقط وقتی انجام می‌شود که موتور تونل را روی همین ویندوز بالا بیاورد و بررسی مستقل IPv4 عبور ترافیک را تأیید کند. اگر هیچ‌کدام از حداکثر پنج کاندید به نتیجه نرسند، برنامه اتصال را تأیید نمی‌کند.

## نصب و اجرا
بستهٔ CI را از GitHub Actions با نام RaahatVPN-Windows-x64 دریافت و تمام محتویات ZIP را در یک پوشه استخراج کنید. برای اجرای ساده، روی فایل شروع-راحت-وی-پی-ان.cmd دوبار کلیک کنید؛ یا مستقیماً RaahatVPN.exe را اجرا کنید. درخواست UAC ویندوز را با انتخاب Yes تأیید کنید. برای ساخت رابط TUN و تغییر مسیر سیستم، برنامه به دسترسی مدیر نیاز دارد. فایل‌های Core و licenses را از پوشه حذف نکنید.

برای اتصال خودکار، کادر سرور را خالی بگذارید و دکمه اتصال را بزنید. برای اتصال دستی، لینک‌های VLESS + REALITY با TCP را هرکدام در یک خط وارد کنید. برای قطع تونل از دکمه قطع اتصال استفاده کنید.

## محدودیت‌های مهم
- این مرحله فقط Windows x64 را بسته‌بندی می‌کند.
- کاتالوگ عمومی ممکن است در شبکه شما مسدود یا موقتاً غیرقابل‌دسترس باشد؛ CDN و mirrorها راه جایگزین‌اند، نه تضمین دسترسی.
- فقط VLESS + REALITY روی TCP اجرا می‌شود. سایر پروتکل‌ها و انتقال‌ها در کلاینت Windows هنوز پشتیبانی نشده‌اند.
- Kill Switch سراسری Windows، Always-on خودکار، split tunneling برنامه‌ای، بازیابی اتصال پس از reboot و به‌روزرسانی درون‌برنامه‌ای پیاده‌سازی نشده‌اند.
- بررسی مستقل IPv4 انجام می‌شود؛ تست مستقل نشت DNS و IPv6، قطع اجباری موتور و جابه‌جایی Wi-Fi به Ethernet هنوز روی دستگاه واقعی لازم است.
- شبکه‌های خصوصی محلی از تونل مستثنا هستند؛ بنابراین Full Tunnel شامل استثناهای LAN است.
- برای مقایسهٔ خروجی IPv4، یک درخواست HTTPS به api.ipify.org فرستاده می‌شود. این سرویس IP درخواست را مشاهده می‌کند؛ این درخواست تله‌متری یا ثبت‌شده توسط Raahat نیست.
- اگر موتور VPN به‌طور غیرمنتظره متوقف شود، این نسخه Kill Switch محافظت‌شده ندارد؛ آن را محافظت‌شده در برابر نشت تلقی نکنید.
- سرورهای عمومی متعلق به اشخاص ثالث و ناشناس هستند. گرداننده سرور از نظر فنی ممکن است بخشی از ترافیک یا فراداده را مشاهده یا ثبت کند. برای بانکداری، حساب‌های حساس یا اطلاعات محرمانه از آن‌ها استفاده نکنید.
- باینری sing-box از انتشار رسمی upstream دریافت و در CI با SHA-256 ثابت بررسی می‌شود. اعلان مجوز GPL-3.0-or-later و پیوند منبع همان نسخه در پوشه licenses بسته قرار دارد.
