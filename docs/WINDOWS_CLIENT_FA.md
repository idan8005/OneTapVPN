# راهنمای کلاینت Windows راحت وی‌پی‌ان

## این نسخه چه کاری انجام می‌دهد؟
- کلاینت WPF با موتور رسمی sing-box نسخهٔ 1.14.4 برای Windows x64 بسته‌بندی می‌شود.
- فقط لینک‌های VLESS + REALITY با انتقال TCP پذیرفته می‌شوند.
- قبل از اتصال، لینک و UUID و پارامترهای REALITY اعتبارسنجی می‌شوند.
- فایل پیکربندی Full Tunnel موقت ساخته می‌شود و قبل از اجرا با دستور `sing-box check` بررسی می‌شود.
- مسیرهای عمومی IPv4 و IPv6 از TUN عبور می‌کنند؛ شبکه‌های خصوصی، loopback و link-local برای دسترسی LAN مستثنا می‌شوند.
- DNS از طریق HTTPS به Cloudflare DoH و از مسیر پروکسی تنظیم شده است.
- وضعیت «خروجی VPN تأیید شد» تنها وقتی نشان داده می‌شود که درخواست HTTPS به `api.ipify.org` پس از اتصال، IP عمومی IPv4 متفاوتی نسبت به پیش از اتصال برگرداند.
- اطلاعات خام لینک یا لاگ موتور در فایل گزارش Raahat ذخیره نمی‌شود.
- Windows Job Object با پرچم Kill-on-close برای بستن پردازش موتور در زمان خروج برنامه استفاده می‌شود.

## نصب و اجرا
بستهٔ CI را از GitHub Actions با نام `RaahatVPN-Windows-x64` دریافت و از ZIP خارج کنید. فایل `RaahatVPN.exe` را اجرا کنید و درخواست UAC ویندوز را تأیید کنید. برای ساخت رابط TUN و تغییر مسیر سیستم، برنامه به دسترسی مدیر نیاز دارد.

لینک سرور VLESS + REALITY را در کادر وارد و «اتصال» را انتخاب کنید. برای قطع تونل از دکمهٔ «قطع اتصال» استفاده کنید.

## محدودیت‌های مهم
- این مرحله فقط Windows x64 را بسته‌بندی می‌کند.
- در این نسخه فقط VLESS + REALITY روی TCP پذیرفته می‌شود. لینک‌های OpenVPN، WebSocket، gRPC و سایر روش‌ها در رابط Windows هنوز پشتیبانی نشده‌اند.
- سرویس انتخاب خودکار/سلامت‌سنجی سرورهای رایگان هنوز به رابط Windows متصل نیست.
- Kill Switch سراسری Windows، Always-on خودکار، split tunneling برنامه‌ای و بازیابی اتصال پس از reboot پیاده‌سازی نشده‌اند.
- بررسی مستقل IPv4 انجام می‌شود؛ تست مستقل DNS، IPv6، قطع اجباری موتور و Wi-Fi به Ethernet هنوز روی دستگاه واقعی باید انجام شود.
- شبکه‌های خصوصی محلی از تونل مستثنا هستند. بنابراین عبارت Full Tunnel در این نسخه شامل این استثناهای LAN است.
- برای مقایسهٔ خروجی IPv4، یک درخواست HTTPS به سرویس مستقل `api.ipify.org` فرستاده می‌شود. این سرویس IP درخواست را مشاهده می‌کند؛ این درخواست تله‌متری یا ثبت‌شده توسط Raahat نیست.
- اگر موتور VPN به‌طور غیرمنتظره متوقف شود، رابط TUN و مسیرهای آن ممکن است از سیستم حذف شوند. این نسخه را به‌عنوان Kill Switch محافظت‌شده تلقی نکنید.
- باینری sing-box از انتشار رسمی upstream دریافت و در CI با SHA-256 ثابت بررسی می‌شود. اعلان مجوز GPL-3.0-or-later و پیوند منبع همان نسخه در پوشهٔ `licenses` بسته قرار دارد.
