# راهنمای کلاینت Windows راحت وی‌پی‌ان

## این نسخه چه کاری انجام می‌دهد؟
- کلاینت WPF با موتور رسمی sing-box نسخه 1.14.4 برای Windows x64 بسته‌بندی می‌شود.
- لینک‌های VLESS + REALITY با انتقال TCP پذیرفته می‌شوند؛ پروفایل‌های OpenVPN، WebSocket، gRPC، XHTTP و دیگر انتقال‌های پشتیبانی‌نشده رد می‌شوند.
- اگر کادر لینک سرور خالی باشد، فهرست عمومی از مخزن FLAT447/v2ray-lists دریافت می‌شود. فقط لینک‌های سازگار با parser برنامه باقی می‌مانند.
- حداکثر پنج کاندید به‌ترتیب امتحان می‌شوند؛ میزبان‌های متفاوت اولویت دارند. همهٔ مقصدها پیش از فعال‌سازی فایروال به IP عمومی IPv4 تبدیل می‌شوند و sing-box از IP ثابت همراه با SNI اصلی TLS استفاده می‌کند.
- اتصال تنها وقتی موفق اعلام می‌شود که درخواست HTTPS از تونل عبور کند و IP عمومی IPv4 با IP پیش از اتصال متفاوت باشد.
- برنامه یک رابط TUN با نام ثابت RaahatVPN، Full Tunnel و strict routing می‌سازد؛ شبکه‌های خصوصی محلی برای دسترسی LAN از مسیر TUN مستثنا هستند.
- چون آدرس DNS رابط TUN به‌صورت صریح تعیین شده، قانون route با action برابر hijack-dns درخواست‌ها را به DNS داخلی sing-box تحویل می‌دهد. DNS-over-HTTPS نیز با detour=proxy داخل تونل می‌رود؛ این مورد از عبور درخواست DNS از مسیر مستقیم جلوگیری می‌کند.

## Kill Switch ویندوز
هنگام اتصال، برنامه Kill Switch سراسری فایروال ویندوز را فعال می‌کند:
1. وضعیت اولیهٔ سه پروفایل فایروال و قوانین خروجی Allow محلی ذخیره می‌شود.
2. یک قانون Allow برای رابط TUN، یک قانون محدود برای IP/پورت سرور sing-box و یک قانون برای محدوده‌های خصوصی LAN ساخته می‌شود.
3. قوانین خروجی Allow محلی که می‌توانند از مسیر فیزیکی عبور کنند، موقتاً غیرفعال می‌شوند و Default Outbound Action هر سه پروفایل روی Block قرار می‌گیرد.
4. یک وظیفهٔ زمان‌بندی‌شده با حساب SYSTEM هر دقیقه قفل خروجی را بررسی می‌کند. اگر نرم‌افزار دیگری هنگام فعال بودن VPN قانون Allow محلی تازه‌ای بسازد، آن قانون هم به نسخهٔ پشتیبان افزوده و تا پایان جلسه غیرفعال می‌شود.
5. هنگام قطع عادی، ابتدا موتور تونل متوقف می‌شود و سپس پروفایل‌ها و قوانین قبلی بازگردانده می‌شوند.

**بازیابی پس از خرابی:** پیش از تغییر فایروال، snapshot در مسیر ProgramData\RaahatVPN\KillSwitch با دسترسی محدود ذخیره و وظیفهٔ SYSTEM ثبت می‌شود. اگر برنامه ناگهانی بسته شود یا ویندوز restart شود، وظیفه فایروال را در حالت Block نگه می‌دارد و قوانین Allow خروجی را غیرفعال می‌کند؛ اینترنت خروجی آزاد نمی‌شود. با اجرای دوبارهٔ راحت‌وی‌پی‌ان، برنامه snapshot را بازیابی می‌کند و سپس اتصال جدید را مجاز می‌سازد. بنابراین پس از crash ممکن است تا بازکردن دوبارهٔ برنامه، اینترنت عادی مسدود بماند؛ این رفتار عمدی است تا ترافیک ناخواسته خارج از VPN عبور نکند.

اگر Group Policy یا قوانین Allow مدیریت‌شدهٔ غیرمحلی وجود داشته باشند، یا فایروال قابل‌کنترل نباشد، فعال‌سازی Kill Switch رد می‌شود و برنامه اتصال را شروع نمی‌کند. اگر بازیابی تنظیمات ناموفق باشد، اتصال جدید غیرفعال می‌ماند و فایروال تا تکمیل بازیابی در حالت Block باقی می‌ماند.

این سازوکار تضمین کامل امنیت یا جلوگیری از تمام نشت‌های شبکه نیست؛ نشت DNS/IPv6، قطع ناگهانی کابل، تغییر شبکه و رفتار نسخه‌های مختلف Windows باید روی دستگاه واقعی آزمایش شوند.

## منبع فهرست رایگان
منبع اولیه فهرست، پروژه عمومی FLAT447/v2ray-lists و فایل BLACK_FULL.txt است. برنامه از CDN jsDelivr و دو mirror عمومی GitHub استفاده می‌کند. Raahat مالک یا گردانندهٔ این سرورها نیست.

وجود لینک در فهرست به معنی سالم بودن آن از شبکهٔ شما نیست. فقط تست خروجی HTTPS روی همان دستگاه می‌تواند اتصال IPv4 را تأیید کند.

## نصب و اجرا
بستهٔ CI را از GitHub Actions با نام RaahatVPN-Windows-x64 دریافت و تمام محتویات ZIP را در یک پوشه استخراج کنید. برای اجرای ساده، روی فایل شروع-راحت-وی-پی-ان.cmd دوبار کلیک کنید؛ یا مستقیماً RaahatVPN.exe را اجرا کنید. درخواست UAC را با انتخاب Yes تأیید کنید. فایل‌های Core و licenses را حذف نکنید.

برای اتصال خودکار، کادر سرور را خالی بگذارید. برای اتصال دستی، حداکثر پنج لینک VLESS + REALITY با TCP را هرکدام در یک خط وارد کنید. برای قطع تونل از دکمهٔ «قطع اتصال» استفاده کنید.

## محدودیت‌های مهم
- این milestone فقط Windows x64 را بسته‌بندی می‌کند.
- Kill Switch سراسری ویندوز با بازیابی محافظت‌شده پیاده‌سازی شده است؛ با این حال، عملکرد واقعی فایروال و بازیابی پس از crash/reboot باید روی رایانه‌های واقعی و نسخه‌های مختلف ویندوز آزمایش شود.
- هنگام crash یا reboot، قفل اینترنت باقی می‌ماند تا برنامه دوباره اجرا شود؛ اگر برنامه باز نشود، اینترنت خروجی ممکن است مسدود بماند.
- قوانین فایروال محلی موجود موقتاً غیرفعال می‌شوند؛ بعد از قطع تونل یا بازیابی توسط اجرای بعدی برنامه، وضعیت ذخیره‌شدهٔ آن‌ها بازگردانده می‌شود.
- اگر کامپیوتر تحت Group Policy یا فایروال سازمانی مدیریت شود، فعال‌سازی در صورت تشخیص قانون Allow مدیریت‌شده رد می‌شود.
- Split tunneling برنامه‌ای، Always-on، اتصال مجدد خودکار پس از reboot و به‌روزرسانی درون‌برنامه‌ای هنوز تکمیل نشده‌اند.
- بررسی خروجی IPv4 با HTTPS انجام می‌شود؛ تست مستقل نشت DNS و IPv6 و جابه‌جایی Wi-Fi به Ethernet هنوز باقی است.
- برای مقایسهٔ خروجی، درخواست HTTPS به api.ipify.org ارسال می‌شود و این سرویس IP درخواست را مشاهده می‌کند.
- سرورهای عمومی متعلق به اشخاص ثالث و ناشناس هستند؛ برای بانکداری، حساب‌های حساس یا اطلاعات محرمانه از آن‌ها استفاده نکنید.
- باینری sing-box از انتشار رسمی upstream دریافت و در CI با SHA-256 ثابت بررسی می‌شود. اعلان مجوز GPL-3.0-or-later در پوشه licenses قرار دارد.
