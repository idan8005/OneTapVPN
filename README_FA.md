# OneTap VPN برای اندروید

این پروژه یک برنامهٔ اندرویدی مبتنی بر کتابخانهٔ WireGuard است. برنامه را نصب و باز کنید و دکمهٔ اتصال را بزنید. در اولین اجرا، اندروید پنجرهٔ تأیید VPN را نمایش می‌دهد؛ این مجوز سیستمی اجباری است.

## ساخت و دریافت APK

- با هر Push به شاخهٔ main یا master، فرایند GitHub Actions خودکار اجرا می‌شود.
- برای اجرای دستی، در مخزن به بخش Actions بروید و گزینهٔ Run workflow را انتخاب کنید.
- پس از موفقیت، از بخش Artifacts فایل OneTapVPN-APK را دانلود کنید.
- ZIP را استخراج و فایل app-debug.apk را روی گوشی نصب کنید.

این خروجی نسخهٔ Debug امضاشده برای نصب و آزمایش است؛ انتشار عمومی به امضای Release اختصاصی نیاز دارد.

## اتصال

- در اولین اتصال، اجازهٔ VPN اندروید را تأیید کنید.
- در صورت نبود پیکربندی ذخیره‌شده، برنامه تلاش می‌کند پیکربندی Cloudflare WARP را دریافت کند.
- از بخش Advanced می‌توانید پیکربندی WireGuard خودتان را از Clipboard وارد کنید.
- API ثبت‌نام WARP غیررسمی است و ممکن است توسط Cloudflare تغییر یا مسدود شود؛ بنابراین اتصال خودکار تضمین‌شده نیست.
- WARP کشور IP را به کشور دلخواه تغییر نمی‌دهد و این پروژه اتصال رایگان نامحدود یا سرعت معینی را تضمین نمی‌کند.

## پیش‌نیازها

ساخت ابری Java 17، Android SDK 34 و Gradle 8.7 را خودکار آماده می‌کند.
