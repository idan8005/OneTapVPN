# راحت وی‌پی‌ان (Raahat VPN)

راحت وی‌پی‌ان یک محصول چندسکویی با معماری ماژولار و مدل ارائه Hybrid است: کشف سرورهای عمومی رایگان در کنار سرورهای اختصاصی Premium.

**پلتفرم‌ها:** Android، Windows و iOS  
**موتورهای موردنظر:** sing-box و OpenVPN  
**WireGuard:** استفاده نمی‌شود.

## ساختار پروژه
- backend/ — API مرکزی و فهرست سرورها با Go
- clients/android/ — کلاینت بومی Kotlin و Jetpack Compose
- clients/windows/ — کلاینت بومی WPF
- clients/ios/ — هسته Swift، فایل‌های اپ SwiftUI و Packet Tunnel Extension
- contracts/ — قرارداد نسخه‌بندی‌شده API
- docs/ — معماری و وضعیت واقعی پیاده‌سازی

## اجرای Backend
پیش‌نیاز: Go نسخه 1.23 یا جدیدتر.

از پوشه backend این دستورها را اجرا کنید:

    go test ./...
    go run ./cmd/api

API به‌صورت پیش‌فرض روی 127.0.0.1:8080 اجرا می‌شود:
- GET /healthz
- GET /api/v1/health
- GET /api/v1/servers

فهرست نمونه عمداً خالی است. هیچ سرور رایگان یا Premium ساختگی داخل برنامه قرار داده نشده است. برای بارگذاری اطلاعات سرورها، متغیر RAAHAT_CATALOG_FILE را به فایل JSON معتبر تنظیم کنید.

برای استقرار عمومی، TLS باید روی خود سرویس یا روی پراکسی معتمد جلوی آن فعال باشد. سرویس HTTP بدون TLS را مستقیماً روی اینترنت منتشر نکنید.

## وضعیت مهم
این نسخه، بازنویسی تمیز و پایه معماری است؛ هنوز اتصال واقعی VPN تکمیل نشده است. کلاینت‌ها تا زمان اتصال موتور واقعی و تست روی دستگاه، وضعیت قطع را نشان می‌دهند و دکمه اتصال غیرفعال است. این رفتار عمدی است تا برنامه هرگز اتصال غیرواقعی را موفق اعلام نکند.

جزئیات در docs/STATUS.md و docs/ARCHITECTURE.md آمده است.
