# OneTap VPN برای اندروید

OneTap VPN یک برنامهٔ سبک اندرویدی بر پایهٔ کتابخانهٔ رسمی WireGuard است. برنامه اتصال و قطع اتصال با یک لمس، تلاش برای ساخت خودکار پروفایل رایگان WARP در اولین اجرا و وارد کردن فایل پیکربندی WireGuard را پشتیبانی می‌کند.

## ساخت و دریافت APK

با هر بار ثبت تغییر در شاخهٔ `main` یا `master`، GitHub Actions به‌صورت خودکار بررسی Lint، آزمون‌های واحد و ساخت APK را اجرا می‌کند.

1. وارد بخش **Actions** مخزن شوید.
2. آخرین اجرای موفق با نام **Build and verify OneTapVPN APK** را باز کنید.
3. از قسمت Artifacts فایل `OneTapVPN-APK` را دریافت و از حالت فشرده خارج کنید.
4. فایل `app-debug.apk` را در گوشی اندرویدی باز و نصب را تأیید کنید.
5. در اولین اتصال VPN، پنجرهٔ مجوز VPN اندروید را نیز تأیید کنید.

فایل فعلی نسخهٔ Debug و مناسب نصب مستقیم و آزمایش است. انتشار عمومی به کلید امضای Release اختصاصی نیاز دارد. هر اجرای GitHub روی یک رایانهٔ موقت انجام می‌شود و ممکن است کلید Debug متفاوتی داشته باشد؛ برای نصب نسخهٔ جدید روی نسخهٔ قبلی، ممکن است لازم باشد نسخهٔ قبلی را حذف کنید. برای به‌روزرسانی بدون حذف برنامه، باید کلید امضای اختصاصی کاربر در GitHub Actions Secrets نگهداری شود.

## روش‌های اتصال

- **پروفایل خودکار WARP:** در اولین اتصال، برنامه تلاش می‌کند یک پروفایل رایگان Cloudflare WARP بسازد. نشانی ثبت‌نام مصرف‌کنندهٔ Cloudflare که برای این قابلیت استفاده می‌شود، API رسمی و تضمین‌شده برای برنامه‌های شخص ثالث نیست و ممکن است تغییر کند یا مسدود شود؛ بنابراین ساخت خودکار پروفایل تضمین‌شده نیست.
- **پروفایل WireGuard شخصی:** فایل `.conf` را وارد کنید یا متن آن را از حافظهٔ موقت جای‌گذاری کنید. حجم پروفایل محدود است و پیش از ذخیره، پیکربندی اعتبارسنجی می‌شود.

پروفایل‌ها با AES-GCM و کلیدی که در Android Keystore نگهداری می‌شود، رمزگذاری می‌شوند. پشتیبان‌گیری از داده‌های برنامه و انتقال دستگاهی غیرفعال است تا پروفایل رمزگذاری‌شده بدون کلید وابسته به همان دستگاه بازیابی نشود. پروفایل متنیِ بدون رمزگذاریِ نسخه‌های قدیمی نیز هنگام نخستین خواندن به فضای رمزگذاری‌شده منتقل می‌شود.

## اصلاحات نسخهٔ 1.1.0

- عملیات VPN در یک صف کاری اجرا می‌شوند تا لمس‌های سریع و تکراری درخواست‌های هم‌زمان ایجاد نکنند.
- قطع اتصال بدون ثبت‌نام مجدد WARP یا بارگذاری پروفایل انجام می‌شود.
- وضعیت واقعی تونل هنگام بازگشت برنامه از backend خوانده و با رابط هماهنگ می‌شود.
- کتابخانهٔ WireGuard به نسخهٔ منتشرشدهٔ جدیدتر ارتقا یافته است.
- پروفایل‌های واردشده و خودکار پیش از ذخیره یا اتصال اعتبارسنجی می‌شوند.
- کلید خصوصی WireGuard با Android Keystore و AES-GCM رمزگذاری می‌شود.
- رابط فارسی، آیکون برنامه، وارد کردن فایل و استثناهای پشتیبان‌گیری اضافه شده‌اند.
- قابلیت Always-on VPN تا زمان پیاده‌سازی و آزمایش مسیر پایدار بازیابی پروفایل عمداً غیرفعال است.

## محدودیت‌های مهم

- اندروید در نخستین اتصال، تأیید مجوز VPN را از کاربر می‌خواهد. این پنجرهٔ سیستمی قابل حذف یا دور زدن نیست.
- WARP امکان انتخاب دلخواه کشور را ارائه نمی‌دهد و این پروژه سرعت، سرویس نامحدود یا دسترس‌پذیری همیشگی را تضمین نمی‌کند.
- خروجی فعلی APK با کلید Debug امضا شده و برای انتشار عمومی مناسب نیست.
