# راحت وی‌پی‌ان (Raahat VPN)

راحت وی‌پی‌ان یک محصول چندسکویی با معماری ماژولار و مدل Hybrid است: سرورهای عمومی Free در کنار زیرساخت اختصاصی Premium.

**پلتفرم‌ها:** Android، Windows و iOS  
**موتورهای موردنظر:** sing-box و OpenVPN  
**WireGuard:** استفاده نمی‌شود.

## ساختار پروژه
- backend/ — API مرکزی و فهرست سرورها با Go
- clients/android/ — کلاینت Kotlin و Jetpack Compose
- clients/windows/ — کلاینت WPF
- clients/ios/ — هسته Swift، SwiftUI و Packet Tunnel Extension
- contracts/ — قرارداد API
- docs/ — معماری، وضعیت پیاده‌سازی و محدودیت‌ها

## اجرای Backend
پیش‌نیاز: Go نسخه 1.23 یا جدیدتر.

از پوشه backend اجرا کنید:

    go test -race ./...
    go run ./cmd/api

API به‌صورت پیش‌فرض روی 127.0.0.1:8080 اجرا می‌شود:
- GET /healthz
- GET /api/v1/health
- GET /api/v1/servers
- GET /api/v1/servers?tier=free
- GET /api/v1/servers?tier=premium

فهرست اولیه نمونه عمداً خالی است. برای بارگذاری سرورهای مدیریت‌شده، مقدار RAAHAT_CATALOG_FILE را به یک فایل JSON معتبر تنظیم کنید.

### کشف سرورهای عمومی Free
آداپتر VPN Gate فقط از API رسمی HTTPS پروژه استفاده می‌کند. برای فعال کردن به‌روزرسانی خودکار در Backend، متغیر زیر را فعال کنید:

    RAAHAT_VPNGATE_ENABLED=true

منبع هر ۲۰ دقیقه به‌روزرسانی می‌شود. فهرست فقط سرورهای OpenVPN با پروفایل TCP معتبر و پورت TCP قابل دسترس را برمی‌گرداند. اگر منبع خطا بدهد یا هیچ نتیجه معتبری نداشته باشد، آخرین فهرست معتبر حذف نمی‌شود.

**محدودیت امنیتی:** این بررسی فقط اتصال TCP به endpoint را تأیید می‌کند؛ ورود OpenVPN یا عبور واقعی ترافیک VPN را ثابت نمی‌کند. سرورهای عمومی VPN Gate داوطلبانه اداره می‌شوند و سیاست ثبت گزارش و قابلیت اعتماد آن‌ها یکسان و تحت کنترل Raahat نیست. برای اطلاعات حساس از سرور عمومی استفاده نکنید.

اطلاعات عمومی سرورها در API فهرست منتشر می‌شود؛ محتوای فایل‌های OpenVPN، کلیدهای خصوصی و اطلاعات احراز هویت در این پاسخ‌ها قرار نمی‌گیرند.

برای استقرار عمومی، TLS باید روی خود سرویس یا پراکسی معتمد جلوی آن فعال باشد. سرویس HTTP بدون TLS را مستقیماً در اینترنت منتشر نکنید.

## وضعیت مهم
Android اکنون هسته sing-box و مسیر پایه VLESS + REALITY را دارد. این به‌روزرسانی، کشف سرور عمومی را در Backend اضافه می‌کند؛ اما کلاینت Android هنوز موتور OpenVPN و دریافت/اتصال به سرورهای VPN Gate را ندارد. Windows و iOS نیز هنوز تونل عملیاتی کامل ندارند. سبز شدن CI به معنی اتصال موفق VPN روی دستگاه واقعی نیست.
