# راحت وی‌پی‌ان (Raahat VPN)

برنامهٔ اندرویدی VPN با رابط فارسی، اتصال WireGuard، راه‌اندازی ساده و پروفایل رمزگذاری‌شده روی دستگاه.

## وضعیت نسخهٔ 1.4.0

- رابط کاربری با Jetpack Compose و Material 3 بازنویسی شده است.
- طراحی تیره، واکنش‌گرا و راست‌به‌چپ برای زبان فارسی.
- اتصال فقط با لمس کاربر آغاز می‌شود؛ پنجرهٔ مجوز سیستمی VPN در اولین استفاده نمایش داده می‌شود.
- مدیریت پروفایل WireGuard در بخش تنظیمات پیشرفته و اختیاری قرار دارد.
- خروجی پروفایل پیش از ذخیره هشدار می‌دهد؛ فایل خروجی شامل کلید خصوصی است.
- اطلاعات پروفایل با AES-GCM و کلید Android Keystore رمزگذاری می‌شود.
- شناسهٔ برنامه ثابت مانده تا نصب نسخه‌های Release امضاشده با همان کلید قابل به‌روزرسانی باشد.

## ساخت

هر Pull Request به شاخهٔ اصلی و هر push روی شاخهٔ اصلی، بررسی Lint، آزمون‌های واحد و ساخت APK آزمایشی را اجرا می‌کند. اگر چهار GitHub Actions Secret امضای ثابت تنظیم شده باشند، Workflow علاوه بر APK، فایل Android App Bundle امضاشده را نیز تولید و اثرانگشت گواهی را بررسی می‌کند.

برای ساخت محلی به JDK 17، Android SDK API 37.1 و Gradle 9.5.0 نیاز است.

## اتصال و محدودیت‌ها

- موتور تونل بر پایهٔ کتابخانهٔ WireGuard for Android است.
- در نصب تازه، برنامه تلاش می‌کند پروفایل Cloudflare WARP را از endpoint مصرف‌کننده ایجاد کند. این endpoint یک API رسمی و تضمین‌شده برای برنامه‌های شخص ثالث نیست؛ ممکن است تغییر کند یا از دسترس خارج شود.
- WARP انتخاب دستی کشور، سرعت مشخص، دسترس‌پذیری همیشگی یا سرویس نامحدود را تضمین نمی‌کند.
- برای سرویس‌های دیگر، می‌توان فایل استاندارد WireGuard با پسوند `.conf` را وارد کرد.
- اتصال خودکار هنگام بازشدن برنامه عمداً فعال نیست؛ کاربر با یک لمس اتصال را آغاز می‌کند.
- مجوز VPN اندروید در اولین استفاده باید توسط خود کاربر تأیید شود و قابل حذف از طرف برنامه نیست.

## امنیت و حریم خصوصی

- پروفایل‌ها با AES-GCM رمزگذاری و کلید رمزگذاری در Android Keystore نگهداری می‌شود.
- فایل خروجی پروفایل حاوی کلید خصوصی است؛ آن را به اشتراک نگذارید.
- هیچ تضمینی دربارهٔ ناشناس‌بودن کامل، عدم ثبت داده از سوی سرویس‌دهندهٔ VPN یا امنیت شبکهٔ مقصد داده نمی‌شود.
- گزارش خطا نباید شامل کلید خصوصی یا محتوای کامل پروفایل باشد.
