# راحت وی‌پی‌ان (Raahat VPN)

راحت وی‌پی‌ان یک کلاینت اندرویدی است که سرورهای رایگان عمومی VPN Gate را
خودکار پیدا می‌کند، بر اساس پینگ، سرعت اعلام‌شده، زمان فعالیت و تعداد نشست‌ها
مرتب می‌کند و با **OpenVPN** به سرور متصل می‌شود. این نسخه از WireGuard استفاده نمی‌کند.

## امکانات

- دریافت خودکار فهرست زندهٔ سرورهای رایگان VPN Gate
- انتخاب سرورهای مناسب بر اساس پینگ، سرعت اعلام‌شده، زمان فعالیت و بار سرور
- امتحان کردن سرور بعدی در صورت رد اتصال، پایان مهلت یا قطع شدن سرور
- اتصال و قطع اتصال با یک لمس
- **فول‌تانل:** عبور ترافیک تمام برنامه‌های گوشی از VPN
- **برنامه‌های انتخابی:** عبور فقط برنامه‌هایی که انتخاب می‌کنید از VPN
- ذخیره انتخاب برنامه‌ها روی گوشی
- بررسی نسخه جدید، دانلود خودکار APK، کنترل SHA-256 و باز کردن نصب‌کننده اندروید
- رابط فارسی و انگلیسی

## هشدار مهم درباره سرورهای رایگان

سرورهای VPN Gate را داوطلبان مستقل اداره می‌کنند و متعلق به راحت وی‌پی‌ان
نیستند. مقدار سرعت و پینگ در فهرست، اندازه‌گیری اعلام‌شده است و سرعت واقعی
شما را تضمین نمی‌کند. سرور ممکن است خاموش، شلوغ یا غیرقابل‌اتصال باشد؛ برنامه
در این حالت سرور بعدی را امتحان می‌کند، اما دسترسی همیشگی یا سرعت مشخص قابل
تضمین نیست.

اپراتور سرور داوطلبانه می‌تواند ترافیک عبوری از سرور خود را مشاهده یا ثبت کند.
برای ورود به حساب بانکی، گذرواژه‌ها، اطلاعات کاری محرمانه یا ترافیک حساس از
سرورهای ناشناس استفاده نکنید. سیاست سوءاستفاده و ثبت گزارش VPN Gate را مطالعه کنید:
https://www.vpngate.net/en/about_abuse.aspx

## روش استفاده

1. APK را نصب کنید.
2. برنامه «راحت وی‌پی‌ان» را باز کنید.
3. حالت «فول‌تانل» یا «برنامه‌های انتخابی» را انتخاب کنید.
4. در حالت برنامه‌های انتخابی، حداقل یک برنامه را تیک بزنید.
5. دکمه «اتصال» را بزنید و مجوز VPN اندروید را تأیید کنید.

برای دریافت فهرست سرورها ابتدا اینترنت لازم است. اگر اولین سرور وصل نشود،
برنامه سرورهای بعدی را خودکار امتحان می‌کند.

اندروید در نخستین اتصال، مجوز VPN را از کاربر می‌خواهد. هنگام به‌روزرسانی
نیز نصب‌کننده اندروید باید تأیید نهایی نصب را از کاربر دریافت کند؛ برنامه‌های
عادی اجازه نصب بی‌صدای نسخه جدید خودشان را ندارند.

## ساخت APK از سورس

پیش‌نیازها: JDK 17، Android SDK Platform 34 و Build Tools 34.0.0.

سورس موتور OpenVPN به‌صورت Git submodule در مخزن قرار گرفته است:

```bash
git clone --recurse-submodules https://github.com/idan8005/OneTapVPN.git
cd OneTapVPN
gradle --no-daemon :app:assembleDebug
```

در صورتی که پروژه را بدون زیرماژول دریافت کرده‌اید:

```bash
git submodule update --init --recursive
```

فایل APK در مسیر زیر ساخته می‌شود:

`app/build/outputs/apk/debug/app-debug.apk`

## ساخت انتشار و به‌روزرسانی داخل برنامه

با هر Push و Pull Request، GitHub Actions نسخه Debug را می‌سازد و آزمایش می‌کند.
برای ساخت نسخه Release باید چهار Secret امضای ثابت که در
[RELEASE_SIGNING_FA.md](RELEASE_SIGNING_FA.md) توضیح داده شده‌اند، در مخزن
ثبت شده باشند. برای تمام نسخه‌های بعدی باید از همان فایل keystore استفاده شود؛
در غیر این صورت اندروید اجازه به‌روزرسانی روی نسخه نصب‌شده را نمی‌دهد.

برای فعال شدن بررسی خودکار نسخه در برنامه:

1. مخزن باید عمومی باشد، یا فایل‌های انتشار از یک نشانی عمومی بدون ورود به
   حساب قابل دریافت باشند. مخزن فعلی خصوصی است و کاربران عادی از داخل APK
   نمی‌توانند API انتشارهای خصوصی آن را بدون احراز هویت بخوانند.
2. چهار Secret امضای Release را ثبت کنید.
3. تگ نسخه، مانند `v1.4.0`، را Push کنید.
4. Workflow نسخه را می‌سازد، امضا و بررسی می‌کند و فایل‌های
   `raahat-vpn.apk` و `raahat-vpn.apk.sha256` را در GitHub Release منتشر می‌کند.

به‌روزرسان برنامه همین دو نام فایل را انتظار دارد. APK پس از دانلود با SHA-256
کنترل می‌شود و سپس نصب‌کننده رسمی اندروید باز می‌شود. ممکن است لازم باشد در
تنظیمات اندروید اجازه نصب برنامه از طرف راحت وی‌پی‌ان را فعال کنید و در پایان
صفحه نصب اندروید را تأیید کنید.

## ساختار پروژه

- `app/`: رابط، دریافت سرورها، تنظیم مسیر برنامه‌ها و به‌روزرسان
- `third_party/OpenGateVPN/vpnLib/`: موتور OpenVPN اندروید
- `VpnGateApi.kt`: دریافت فهرست عمومی و رتبه‌بندی سرورها
- `VpnManager.kt`: ساخت پروفایل OpenVPN، تنظیم فول‌تانل/برنامه‌های انتخابی و اتصال
- `VpnViewModel.kt`: وضعیت اتصال و جابه‌جایی خودکار بین سرورها
- `AppUpdater.kt`: دریافت نسخه، دانلود APK و کنترل صحت فایل

## آزمایش روی گوشی واقعی

ساخت موفق در CI یا شبیه‌ساز به معنی آزمایش اتصال واقعی روی گوشی، اینترنت
موبایل، Wi-Fi یا سرور VPN Gate نیست. پیش از استفاده، برنامه را روی گوشی واقعی
آزمایش کنید. از عبور اطلاعات حساس از سرورهای داوطلبانه خودداری کنید.
