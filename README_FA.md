# راحت وی‌پی‌ان (Raahat VPN)

راحت وی‌پی‌ان یک محصول چندسکویی با مدل Hybrid است: سرورهای عمومی رایگان در کنار زیرساخت اختصاصی Premium.

**پلتفرم‌ها:** Android، Windows و iOS  
**موتور Android:** sing-box 1.14.4 برای VLESS + REALITY و OpenVPN  
**WireGuard:** استفاده نمی‌شود.

## ساختار پروژه
- backend/ — API مرکزی، کاتالوگ سرورها و آداپترهای منابع عمومی با Go
- clients/android/ — کلاینت Kotlin و Jetpack Compose
- clients/windows/ — کلاینت WPF
- clients/ios/ — هسته Swift و مسیر تکمیل Network Extension
- contracts/ — قرارداد API
- docs/ — معماری و وضعیت واقعی پیاده‌سازی

## Android — سرورهای رایگان
با انتخاب «اتصال خودکار رایگان»، برنامه مستقیماً فهرست CSV رسمی VPN Gate را از HTTPS دریافت می‌کند. سپس:
- پروفایل‌های OpenVPN را از داخل برنامه بررسی می‌کند و فقط آدرس و میزبان منطبق با رکورد منبع را می‌پذیرد.
- پروفایل‌های TCP را با آزمایش پورت TCP فیلتر می‌کند.
- پروفایل‌های UDP را جدا نگه می‌دارد؛ UDP با تست TCP قابل سنجش نیست و باید با دست‌دهی OpenVPN آزمایش شود.
- سرورهای پیدا‌شده را با پینگ منبع مرتب می‌کند و سریع‌ترین گزینه‌ها را برای اتصال امتحان می‌کند.
- اگر تونل یا آزمایش مستقل HTTPS شکست بخورد، حداکثر سه کاندید برتر را به‌ترتیب امتحان می‌کند.

فایل پروفایل و اطلاعات ورود فقط در حافظه برنامه استفاده می‌شوند؛ در API فهرست عمومی یا لاگ‌ها قرار نمی‌گیرند. پیکربندی نهایی قبل از شروع تونل با `Libbox.checkConfig` بررسی می‌شود و برنامه فقط پس از تأیید عبور HTTPS وضعیت «متصل» را اعلام می‌کند.

**محدودیت امنیتی:** سرورهای VPN Gate را داوطلبان مستقل اداره می‌کنند و ممکن است ترافیک را ثبت کنند؛ برای اطلاعات حساس مناسب نیستند. برای TCP، پاسخ پورت فقط پیش‌سنجی است. برای UDP، معیار نهایی دست‌دهی واقعی و عبور ترافیک از تونل است.

## Backend
پیش‌نیاز: Go نسخه 1.23 یا جدیدتر.

از پوشه backend اجرا کنید:

    go test -race ./...
    go run ./cmd/api

API به‌صورت پیش‌فرض روی 127.0.0.1:8080 اجرا می‌شود:
- GET /healthz
- GET /api/v1/health
- GET /api/v1/servers
- GET /api/v1/servers?tier=free
- GET /api/v1/servers?tier=premium

کاتالوگ اولیه عمداً خالی است. برای بارگذاری سرورهای مدیریت‌شده، مقدار `RAAHAT_CATALOG_FILE` را به فایل JSON معتبر تنظیم کنید.

آداپتر Backend برای VPN Gate مستقل از اسکن مستقیم Android است و در حال حاضر فقط پروفایل‌های TCP را وارد کاتالوگ سلامت‌سنجی می‌کند. برای فعال کردن به‌روزرسانی کاتالوگ، مقدار `RAAHAT_VPNGATE_ENABLED=true` را تنظیم کنید. منبع هر ۲۰ دقیقه به‌روزرسانی می‌شود و خرابی منبع باعث پاک‌شدن آخرین کاتالوگ معتبر نمی‌شود.

برای استقرار عمومی، TLS باید روی سرویس یا پراکسی معتمد جلوی آن فعال باشد. سرویس HTTP بدون TLS را مستقیماً در اینترنت منتشر نکنید.

## وضعیت انتشار
نسخه 0.3.0-dev یک نسخه توسعه است. CI ساخت Android و تست‌های کد را بررسی می‌کند، اما هنوز تست اتصال روی چند دستگاه واقعی، بررسی DNS/IPv6 و آزمون امنیتی مستقل انجام نشده است. Windows و iOS هنوز تونل عملیاتی کامل ندارند. Premium، سرویس پرداخت، سرورهای مدیریت‌شده و به‌روزرسانی امضاشده نیز در حال تکمیل‌اند.
