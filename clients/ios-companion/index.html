سرورهای بررسی‌شده

نشانی سرویس API راحت وی‌پی‌ان را وارد کن تا فهرست سرورهای فعال دریافت شود. این بخش فقط اطلاعات سرورها را نشان می‌دهد.

نشانی API هنوز وارد نشده است.

برای سرورهای عمومی VPN Gate، پاسخ‌دادن پورت TCP فقط دسترسی اولیه را نشان می‌دهد؛ به‌معنای موفقیت اتصال OpenVPN، سرعت واقعی یا امنیت سرور نیست. این صفحه هنوز تونل VPN برقرار نمی‌کند و نشانی API را ذخیره نمی‌کند.

OpenVPN

پروفایل OpenVPN را وارد کن

فایل ‎.ovpn را انتخاب کن. این صفحه ساختار پایه و وابستگی‌های خارجی پروفایل را بررسی می‌کند و سپس فایل را برای OpenVPN Connect آماده می‌کند.

هنوز فایلی انتخاب نشده است.

پروفایل فقط در حافظه همین صفحه خوانده می‌شود و روی سرور یا فضای ذخیره‌سازی مرورگر ذخیره نمی‌شود. قبل از واردکردن، منبع فایل را بررسی کن.

VLESS / REALITY

بازکردن لینک در Hiddify

لینک یک سرور یا لینک اشتراک را وارد کن. این بخش فقط لینک‌های VLESS را آماده می‌کند و تونل VPN را خودش اجرا نمی‌کند.

لینک را وارد کن.

راهنمای نصب

  1. برای ‎.ovpn، برنامه OpenVPN Connect را از App Store نصب کن.
  2. برای VLESS، در صورت موجودبودن در منطقه حساب Apple، Hiddify را نصب کن.
  3. پس از واردکردن پروفایل، درخواست iOS برای افزودن VPN را بررسی و تأیید کن.

این همراه وب، نسخه مستقل VPN نیست. تونل را برنامه OpenVPN Connect یا Hiddify اجرا می‌کند. سرورهای عمومی ممکن است ناپایدار باشند یا ترافیک را ثبت کنند؛ برای اطلاعات حساس از آن‌ها استفاده نکن.
