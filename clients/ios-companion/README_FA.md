# همراه وب آیفون Raahat VPN

## وضعیت این نسخه

این یک وب‌اپلیکیشن آزمایشی (PWA) برای iPhone است؛ خودش موتور VPN یا سرور VPN ندارد. تونل را برنامهٔ ثالث اجرا می‌کند.

## قابلیت‌های فعلی

- رابط فارسی و راست‌چین، سازگار با صفحهٔ موبایل.
- دریافت خودکار کاتالوگ عمومی از API مستقرشدهٔ راحت وی‌پی‌ان با درخواست `GET /api/v1/servers`؛ نشانی سرویس از پیش تنظیم است و کاربر لازم نیست آن را وارد کند.
- نمایش فقط رکوردهای فعال و سالم؛ سرور VPN Gate تنها وقتی نشان داده می‌شود که بررسی TCP سمت Backend برای آن موفق شده باشد.
- نمایش کشور، منطقه، نشانی میزبان/پورت، زمان پاسخ ثبت‌شده و آخرین زمان بررسی، در صورت وجود.
- زمان‌پاسخ TCP با برچسب دقیق نمایش داده می‌شود؛ این سنجش، دست‌دهی OpenVPN یا عبور ترافیک VPN را اثبات نمی‌کند.
- انتخاب فایل `.ovpn` و بررسی اولیهٔ ساختار، دستور `remote`، پروتکل و ارجاع به فایل‌های جانبی.
- ردکردن پروفایل‌هایی که به فایل‌های خارجی نیاز دارند؛ این نسخه فقط فایل خودکفا با گواهی/کلید inline را می‌پذیرد.
- اشتراک فایل با Share Sheet در مرورگرهای پشتیبانی‌شده یا ذخیرهٔ فایل برای واردکردن دستی در OpenVPN Connect.
- اعتبارسنجی ابتدایی لینک VLESS و کپی آن یا تلاش برای بازکردن Hiddify.
- پوستهٔ آفلاین PWA برای فایل‌های ثابت؛ کاتالوگ سرورها برای دریافت اطلاعات تازه به اینترنت و API آنلاین نیاز دارد.

## اتصال به API کاتالوگ

1. صفحهٔ همراه آیفون: `https://raahat-iphone-companion.onrender.com`.
2. API مرکزی: `https://raahat-vpn-api.onrender.com`.
3. سرویس API با HTTPS اجرا می‌شود و دریافت VPN Gate هر ۲۰ دقیقه به‌روزرسانی می‌شود.
4. نشانی API در صفحه از پیش ثبت شده و فهرست با بازشدن صفحه خودکار دریافت می‌شود؛ دکمه برای تازه‌سازی دستی نیز وجود دارد.

API باید مسیر `GET /api/v1/servers` را در دسترس بگذارد. این API فقط فرادادهٔ عمومی سرور را برمی‌گرداند، نه فایل پروفایل OpenVPN، کلید خصوصی، رمز یا URI اتصال VLESS. بنابراین نمایش یک سرور در این صفحه به‌معنای امکان اتصال مستقیم از این PWA نیست.

### CORS و میزبانی

- مقدار `RAAHAT_CORS_ALLOWED_ORIGINS` فهرست جداشده با کامای originهای مجاز است؛ برای نمونه `https://account.github.io`.
- مقدار پیش‌فرض `*` فقط برای API عمومیِ فقط‌خواندنی در نظر گرفته شده است. درخواست‌ها بدون credential ارسال می‌شوند و API هیچ مسیر نوشتن از مرورگر ارائه نمی‌دهد.
- برای میزبانی عمومیِ کنترل‌شده، بهتر است origin دقیق وب‌سایت در این متغیر قرار گیرد.
- Backend متغیر `PORT` محیط میزبانی را می‌خواند. اگر HTTPS در پراکسی مورداعتماد خاتمه می‌یابد، `RAAHAT_TLS_TERMINATED_BY_PROXY=true` را فقط در همان محیط تنظیم کنید.
- Backend در حال حاضر کاتالوگ را در حافظه نگه می‌دارد؛ پس از راه‌اندازی مجدد، منبع VPN Gate دوباره دریافت می‌شود. در این مرحله پایگاه دادهٔ پایدار برای کاتالوگ وجود ندارد.
- نشانی API که کاربر در PWA وارد می‌کند در مرورگر ذخیره نمی‌شود. پاسخ کاتالوگ نیز با `cache: no-store` دریافت می‌شود.

## حریم خصوصی و محدودیت‌ها

- محتوای پروفایل و لینک VLESS در localStorage، IndexedDB، کوکی یا سرور ذخیره نمی‌شود.
- برنامه برای اعتبارسنجی، فایل را فقط در حافظهٔ همان صفحه می‌خواند.
- بررسی ساختاری به معنی اتصال‌پذیری، سالم‌بودن سرور، نبود بدافزار یا امنیت ارائه‌دهنده نیست.
- پروفایل OpenVPN ممکن است حاوی نام کاربری، رمز یا گواهی خصوصی باشد؛ فقط فایل‌هایی را وارد کنید که به منبع آن‌ها اعتماد دارید.
- بازکردن Hiddify به نصب‌بودن برنامه و پشتیبانی iOS از scheme وابسته است؛ اگر باز نشد لینک را کپی و در برنامه وارد کنید.
- این PWA تونل برقرار نمی‌کند، پروفایل را از API دانلود نمی‌کند و انتخاب/اتصال خودکار سرور ندارد.
- سرورهای VPN Gate را داوطلبان مستقل اداره می‌کنند و ممکن است ناپایدار باشند یا ترافیک را ثبت کنند؛ برای اطلاعات حساس مناسب نیستند.
- در iOS، نصب PWA نیازمند میزبانی HTTPS است. فایل ZIP خروجی CI به‌تنهایی یک آدرس عمومی قابل نصب ایجاد نمی‌کند.

## نصب روی iPhone

1. لینک `https://raahat-iphone-companion.onrender.com` را در Safari باز کنید.
2. دکمهٔ Share را بزنید.
3. گزینهٔ Add to Home Screen را انتخاب و تأیید کنید.

سایت و API روی Render میزبانی می‌شوند. سرویس رایگان API ممکن است پس از مدتی بی‌استفاده‌ماندن موقتاً متوقف شود؛ نخستین درخواست بعدی ممکن است دیرتر پاسخ بدهد. صفحه برای این بیدارشدن زمان انتظار بیشتری در نظر می‌گیرد. Workflow **Raahat iPhone companion** نحو JavaScript، manifest و قرارداد دریافت کاتالوگ را بررسی و ZIP آزمایشی می‌سازد.

## آزمون دستی پیش از انتشار

1. API با یک فهرست آزمایشی فعال و یک origin مجاز اجرا شود.
2. دریافت کاتالوگ از صفحهٔ HTTPS بررسی شود؛ رکورد غیرفعال یا ناسالم نباید نمایش داده شود.
3. سرور VPN Gate بدون `tcp-reachable` نباید در صفحه نشان داده شود.
4. یک پروفایل OpenVPN خودکفا و یک پروفایل دارای ارجاع فایل خارجی آزمایش شود.
5. فایل معتبر با Share Sheet به OpenVPN Connect منتقل و import شود.
6. لینک VLESS کپی و در Hiddify وارد شود.
7. نصب به Home Screen و حالت آفلاین پوسته در Safari آزمایش شود.

هیچ اتصال VPN واقعی یا تست نشت DNS/IPv6 توسط این وب‌اپ انجام نمی‌شود.
