راهنمای اجرای راحت وی‌پی‌ان در ویندوز

1. فایل ZIP را به‌طور کامل در یک پوشه استخراج کنید.
2. فایل شروع-راحت-وی-پی-ان.cmd یا RaahatVPN.exe را اجرا کنید.
3. در پیام Windows UAC گزینه Yes را بزنید. این مجوز برای ساخت رابط TUN و تنظیم مسیر شبکه لازم است.
4. برای اتصال خودکار، کادر لینک سرور را خالی بگذارید. برنامه فهرست عمومی را دریافت و فقط لینک‌های سازگار VLESS + REALITY با انتقال TCP را انتخاب می‌کند. در صورت تمایل می‌توانید حداکثر ۵ لینک را به‌صورت دستی وارد کنید.
5. دکمه اتصال را بزنید. برنامه حداکثر پنج سرور را به‌ترتیب امتحان می‌کند و فقط سروری را نگه می‌دارد که بررسی HTTPS خروجی IPv4 از طریق تونل موفق شود.
6. برای قطع اتصال از دکمه قطع اتصال استفاده کنید.

منبع فهرست عمومی:
- پروژه FLAT447/v2ray-lists
- دریافت از CDN عمومی و دو آدرس جایگزین GitHub
- این فهرست متعلق به Raahat نیست؛ وضعیت سرورها ممکن است در هر لحظه تغییر کند و دسترسی از شبکه شما تضمین‌شده نیست.

مهم:
- کل پوشه را استخراج کنید. فایل RaahatVPN.exe به Core\sing-box.exe و فایل‌های runtime کنار خود نیاز دارد.
- این نسخه فقط VLESS + REALITY روی TCP را پشتیبانی می‌کند. لینک‌های OpenVPN، WebSocket، gRPC، XHTTP و پروتکل‌های دیگر پذیرفته نمی‌شوند.
- لینک‌های منبع عمومی فقط کاندید اولیه‌اند؛ اتصال هر سرور باید از شبکه خود شما و با عبور واقعی ترافیک IPv4 تأیید شود.
- Kill Switch ویندوز هنوز پیاده‌سازی نشده است. این نسخه را محافظت‌شده در برابر نشت هنگام قطع ناگهانی موتور فرض نکنید.
- انتخاب برنامه‌ها (split tunneling) و اتصال مجدد خودکار هنوز آماده نیستند.
- در صورت نمایش خطا یا تأیید نشدن خروجی، اتصال را سالم فرض نکنید.
- سرورهای عمومی متعلق به اشخاص ناشناس ممکن است کند، ناپایدار یا ثبت‌کننده ترافیک باشند. اطلاعات حساس، بانکی یا رمزهای مهم را از آن‌ها عبور ندهید.
- برای تأیید خروجی IPv4، یک درخواست HTTPS به api.ipify.org ارسال می‌شود؛ این سرویس بیرونی ممکن است IP خروجی را مشاهده کند.
- این نسخه توسعه‌ای است و هنوز به آزمایش واقعی روی دستگاه‌ها و شبکه‌های گوناگون نیاز دارد.
