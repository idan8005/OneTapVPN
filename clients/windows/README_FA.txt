راهنمای اجرای راحت وی‌پی‌ان در ویندوز

1. فایل ZIP را به‌طور کامل در یک پوشه استخراج کنید.
2. فایل START_RAAHAT_VPN.cmd یا RaahatVPN.exe را اجرا کنید.
3. در پیام Windows UAC گزینه Yes را بزنید. این مجوز برای ساخت رابط TUN و تنظیم مسیر شبکه لازم است.
4. لینک سرور VLESS + REALITY با انتقال TCP را در برنامه وارد کنید.
5. اتصال را بزنید و منتظر بمانید تا وضعیت بررسی خروجی IPv4 نمایش داده شود.
6. برای قطع اتصال از دکمه قطع اتصال استفاده کنید.

مهم:
- کل پوشه را استخراج کنید. فایل RaahatVPN.exe به Core\sing-box.exe و فایل‌های runtime کنار خود نیاز دارد.
- این نسخه فقط VLESS + REALITY روی TCP را پشتیبانی می‌کند.
- Kill Switch ویندوز هنوز در این نسخه پیاده‌سازی نشده است.
- در صورت نمایش «تونل فعال؛ اتصال تأییدنشده»، استفاده از اینترنت را از مسیر VPN قطعی فرض نکنید.
- این نسخه توسعه‌ای است و هنوز روی دستگاه واقعی و چند نوع شبکه آزمایش نشده است.
- سرورهای عمومی ممکن است کند، ناپایدار یا ثبت‌کنندهٔ ترافیک باشند. اطلاعات حساس را از آن‌ها عبور ندهید.
